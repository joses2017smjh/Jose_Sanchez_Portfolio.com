title: "Point Cloud Classification"
summary: "Point-based deep learning models that classify 3D objects from raw point clouds."
problem: >-
  Point clouds are unordered and irregular, so standard CNNs don't apply: a
  model has to be invariant to point permutation while still capturing local
  spatial structure and long-range relationships.
approach: >-
  Designed point-based architectures inspired by PointNet and
  PointConvFormer, combining shared per-point encoders with attention over
  local neighborhoods to model spatial relationships directly on raw points.
  Trained and evaluated on the ModelNet and ShapeNet benchmarks, with the
  same sampling budget across variants so the comparison isolates the
  architecture.
result: >-
  Working 3D object classifiers on ModelNet and ShapeNet; attention-based
  variants improved classification performance over the PointNet-style
  baseline. Graduate coursework — code not publicly released.

      points each.

    body: >-
      Self-attention over local neighborhoods recovers the fine structure
      PointNet throws away, lifting accuracy across ModelNet10. The residual
      errors concentrate exactly where geometry alone is ambiguous — a flat
      slab on legs reads as desk or table, and no amount of attention settles
      which.
