title: Agentic Match Forecasting
summary: >-
  A forecasting prototype connecting probability models, MCP tools, and a reviewable agent
  workflow.
problem: >-
  A forecast interface needs consistent probabilities, visible uncertainty, and traceable
  inputs. An agent also needs clear boundaries between generating an analysis and acting on
  a recommendation.
approach: >-
  Combined XGBoost, calibration, and prediction sets with a Dixon-Coles score grid. A
  FastAPI gateway connects a LangGraph orchestrator to three MCP servers; a separate
  simulator evaluates staking policies and reward behavior.
result: >-
  The historical World Cup report records 0.9013 log loss and 62.7% accuracy on 102 matches
  with pre-tournament training. The served artifact and upstream tool backends are demos.
  Historical calibration splits still need stronger isolation.
