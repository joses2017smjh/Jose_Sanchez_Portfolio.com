title: Agentic Soccer MCP
summary: Inspect match forecasts, model uncertainty, and the tool calls behind an agent’s analysis.
problem: A forecast interface needs consistent probabilities, visible uncertainty, and traceable inputs.
  An agent also needs clear boundaries between generating an analysis and acting on a recommendation.
approach: Combined XGBoost, calibration, and prediction sets with a Dixon-Coles score grid. A FastAPI
  gateway connects a LangGraph orchestrator to MCP data and prediction tools; a separate simulator evaluates staking
  policies and reward behavior.
result: >-
  Published EPL walk-forward report, 1,520 matches: model log loss 1.0229 versus
  1.0652 naive and 0.9407 closing market (lower is better). Coverage is 86.9%
  against a 90% target. The hosted app uses a synthetic model and demo backends;
  historical results are a separate evaluation.
