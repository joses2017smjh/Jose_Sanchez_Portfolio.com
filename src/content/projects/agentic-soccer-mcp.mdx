title: "Agentic Soccer Prediction over MCP"
summary: "Calibrated match forecasts served by a LangGraph agent across three MCP servers, with human approval before any stake."
problem: >-
  Betting markets are a strong probability oracle, so the interesting problem
  isn't beating them — it's producing forecasts that are calibrated,
  internally consistent across correlated markets, and honest about their own
  uncertainty, then serving them through an agent where every number traces
  back to a tool call.
approach: >-
  Phase A is an offline stack: leakage-guarded features into XGBoost with
  isotonic calibration and split-conformal sets, a Dixon-Coles score grid
  reconciled exactly to its own marginals, plus goal-timing and player-prop
  layers, shipped as one versioned artifact bundle. Phase B serves it — a
  FastAPI gateway into a LangGraph orchestrator driving three MCP servers
  (odds, news/injuries, inference), with a human-in-the-loop interrupt before
  any staking suggestion and conformal sets the agent must surface.
result: >-
  On 102 real World Cup 2026 matches, trained strictly pre-tournament: 0.9013
  log loss and 62.7% accuracy vs 47.1% for the prior, with conformal coverage
  at 0.951 against a 0.90 target. On EPL the closing line wins and the report
  says so.
