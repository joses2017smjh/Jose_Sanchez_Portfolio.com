title: "Agentic Soccer Prediction over MCP"
summary: "Calibrated match forecasts served by a LangGraph agent across three MCP servers, with human approval before any stake."
problem: >-
  Betting markets provide robust probability estimates, so the challenge is not
  outperforming them but generating forecasts that are calibrated, internally
  consistent across correlated markets, and transparent about uncertainty —
  served through an agent where every number traces back to a tool call.
approach: >-
  Phase A is an offline pipeline: leakage-guarded features feed XGBoost,
  followed by isotonic calibration and split-conformal prediction sets. A
  Dixon-Coles score grid is reconciled to its own marginal distributions, with
  goal-timing and player-prop layers added for granularity, and the whole stack
  versioned as a single artifact bundle. Phase B exposes that artifact via a
  FastAPI gateway orchestrated by LangGraph across three MCP servers (odds,
  news/injuries, inference), with a human-in-the-loop interrupt enforced before
  any staking recommendation and conformal sets the agent must surface.
result: >-
  Evaluation on 102 World Cup 2026 matches, trained exclusively on
  pre-tournament data, yielded 0.9013 log loss and 62.7% accuracy against 47.1%
  for the baseline, with conformal coverage at 0.951 against a 0.90 target. On
  EPL the closing line outperformed the model, and the report says so.

      not overcome the vig. The value is calibrated structure, not

      tools fail loudly rather than bluffing.
