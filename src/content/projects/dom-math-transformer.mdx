title: "DoM: Decoder-Only Transformer for Math Word Problems"
summary: "A from-scratch transformer that turns math word problems into executable computation graphs."
problem: >-
  Math word problems require mapping free-form language onto a precise
  sequence of operations. Generic seq2seq models routinely emit malformed
  programs that can't be executed at all, so accuracy collapses exactly where
  correctness matters most.
approach: >-
  Co-developed a decoder-only seq2seq transformer built from scratch in
  PyTorch — custom vocabularies, dataloader, and training loop — trained on
  the MathQA dataset (~30k problems). Designed smart_sample, a constrained
  decoding method that restricts each generation step to tokens that keep the
  program a valid, executable DAG, so structural failure is ruled out by
  construction rather than filtered afterwards.
result: >-
  77.45% exact-match accuracy, 84.78% BLEU, and 2.72 average graph edit
  distance on the MathQA test set, with constrained decoding guaranteeing
  valid graph construction on every sample.

    body: >-
      Two failure modes from the same run. On the short problem the model
      over-generates, wrapping a correct division in operations the gold
      program never asks for. On the long one it under-generates, collapsing
      an 18-operation partnership problem into four. Both are still valid
      executable graphs — constrained decoding guarantees structure, not
      semantics.

      semantic, and no amount of extra training fixes a model that builds a
      well-formed graph of the wrong operations.
