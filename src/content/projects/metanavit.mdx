## Where it goes next

The honest gap is that this version has no numbers attached to it. v2 starts
with an eval harness — a frozen corpus, a hand-labeled question set, and
retrieval metrics reported alongside latency — so every change after it can be
measured rather than asserted.

Then the retrieval itself: hybrid BM25 and dense search fused with reciprocal
rank fusion, a cross-encoder reranker, and late chunking so each chunk vector
carries its document's context. After that, the architecture shifts — moving
retrieval inside a LangGraph agent loop that rewrites its own queries, and
exposing the corpus as an MCP server so any client can drive it.
