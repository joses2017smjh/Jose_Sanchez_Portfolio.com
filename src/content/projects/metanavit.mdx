title: "MetaNaviT: Retrieval over Research Files"
summary: >-
  Find the current configuration, trace the supporting files, and review proposed changes
  before applying them.
problem: >-
  Research folders contain active configs, archived drafts, logs, and checkpoints. Finding a
  plausible answer is easier than identifying the current file and returning traceable
  evidence.
approach: >-
  Combined BM25 and dense retrieval with reciprocal rank fusion, query routing, staleness
  filtering, and typed graph traversal. Exposed search and proposed filesystem changes
  through an MCP interface.
result: >-
  The committed 136-query fixture benchmark reports Recall@50 0.938 and nDCG@10 0.493 using
  hash embeddings and overlap reranking. On eight exact-path queries, adding routing after
  reranking increased nDCG@10 from 0.875 to 0.938.
