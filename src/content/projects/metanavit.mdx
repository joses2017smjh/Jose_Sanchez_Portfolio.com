title: "MetaNaviT: Agentic RAG over Research Files"
summary: Find the current file, trace the evidence, and review proposed changes before an agent applies them.
problem: Research folders contain active configs, archived drafts, logs, and checkpoints. Finding a plausible
  answer is easier than identifying the current file and returning traceable evidence.
approach: Combined BM25 and dense retrieval with reciprocal rank fusion, query routing, staleness filtering,
  and source tracing. Exposed search and proposed filesystem changes through an MCP interface.
result: 'SciFact, 300 queries: hybrid retrieval plus reranking improves paired nDCG@10 by 0.075
  (95% bootstrap CI 0.053–0.101) over BM25. The fp16/cap-512 GPU configuration
  cuts in-memory benchmark query p50 from 923 to 191 ms with no statistically detected ranking change.'
